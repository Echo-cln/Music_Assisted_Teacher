# 乡音智谱

**面向乡村小学音乐课堂的备课、课堂记录与数字编曲 Web 应用。**

乡音智谱把班级画像、歌曲与教学资源、教案准备、课堂音频分析、课后反馈和数字编曲放在同一个工作台中。教师可以从班级情况和歌曲出发准备教案，在课堂后记录观察与改进，并将音频分析结果关联到具体课程。

项目面向音乐教学辅助。教案可编辑并由教师审核；音频分析受录音质量、设备和环境影响，适合辅助观察，不替代教师判断或正式测评。

> **当前推荐方式：本地运行完整应用。** 前端由 FastAPI 一并提供，默认使用本机 SQLite；无需先部署云端后端或配置 Supabase。模型、邮箱验证码、人声分离和图片识谱等能力按需配置。

## 项目能做什么

乡音智谱围绕一节音乐课的前、中、后期工作设计：

1. 维护班级画像和教学资源；
2. 按歌曲、班级情况、课时和教师要求准备教案；
3. 在数字工作台输入或导入旋律，试听、编配和保存作品；
4. 记录课堂录音，分别做课堂整体观察或单人练唱逐音比较；
5. 把音频记录、课堂反馈和教案归档，供后续查阅与调整。

系统提供登录和教师数据归属控制。默认数据库和上传文件保存在本机，因此这份说明所述的多教师隔离是应用数据模型能力；它本身不代表项目已经部署成可供多人远程访问的在线服务。

### 音频分析的两种用途

**课堂整体分析**关注一段课堂录音的整体声学表现，例如音高稳定性、节拍规律、力度变化和声音清晰度，并按时间片段呈现观察。它不是逐个学生的独立评分。配置模型后，模型可根据已提取的声学依据整理教学建议；模型不负责从录音中凭空判定学生表现。

**单人练唱逐音评测**需要一段主旋律参考和一段学生练唱录音。系统尝试做旋律对齐，再呈现音高/时值差异。参考旋律为清晰独唱时更适合比较；参考为原唱伴奏混音时需要 Demucs。参考旋律缺失、声部无法分离或录音不清晰时，不应把结果当作可靠跑调评分。

### 数字乐器与音色

- 钢琴键盘用于输入音符；音色选择改变试听声音，不改变音符的钢琴键位。
- 可在编曲工程中设置旋律、速度、拍号、格数和小节数量，再生成不同风格的多轨安排。
- 工作台包含钢琴、小提琴、原声吉他、古筝、二胡和非洲鼓等乐器选项。具体能否播放真实对应音色，取决于内置采样或你导入并绑定的 SF2 音源；没有可用采样的声部不会自动变成真实乐器音色。
- 导入的本机 SF2 音色包保存在当前浏览器的 IndexedDB；可重命名、绑定多个乐器、预览试听、完整旋律试听、启用或移除。清理浏览器站点数据、换浏览器或设备会影响这份本机库。
- 若 FastAPI 与 Supabase Storage 已配置，工作台还提供账号云端音色包的上传、下载和删除。只在本机运行且未配置 Supabase 时，使用本机音色库即可。
- 仓库不附带第三方音色包。请确认下载和使用的 SF2 许可允许你的用途。

## 典型使用流程

### 1. 建立班级画像

打开 **班级画像 → 新建班级**，填写班级名称、年级、省份、人数、学习水平、活跃度、合作情况、音准节奏基础和教师观察。保存后，教案助手可读取这些信息用于推荐和备课。

建议把画像写成具体观察，例如“多数学生能跟随稳定四拍，长音容易提前收尾”，少写无法帮助备课的笼统评价。

### 2. 维护歌曲和资源

打开 **教学资源库**，在歌曲、音乐游戏、乐理、易错纠正等分类中搜索。系统条目可查看或复制为个人资源；自己的条目可继续编辑。若歌曲资料不符合实际，请先核对再用于教案。

### 3. 生成并保存教案

打开 **AI 教案助手**：

1. 选“智能推荐”或“手动指定”歌曲；
2. 选择班级、课时和课堂偏好；
3. 选择快速或深度模式，填写设备条件、学生特点或其他具体要求；
4. 等待生成任务完成；生成期间可查看任务步骤和状态；
5. 阅读教案预览，按需填写调整要求并继续调整；
6. 确认内容后点击 **保存教案**。

快速模式的目标仍然是完整、具体、可编辑的教案；快速指希望更快生成，不代表只返回短模板。生成内容需要教师核对。点击保存前的预览不会自动成为教学档案。

### 4. 备课或导入乐谱

打开 **数字乐器与编曲**，可以直接输入音名（如 `C4 D4 E4 G4`，`R` 表示休止），也可以通过钢琴键盘和卷帘编辑音符。

- MusicXML / MIDI：点击“导入乐谱”直接导入；
- PNG / JPG / WEBP / TIFF / PDF：需要先在后端电脑安装 Audiveris，再从界面导入；
- 点击试听控制设置 BPM、拍号、格数和小节数；
- 点击生成/更新多轨编曲，选择风格、音色后试听；
- 工程会保存在应用数据库中；本机音色包则保存在当前浏览器中。

初次体验可使用工作台的“下载示例”，仓库也提供 [MusicXML 测试乐谱](frontend/assets/samples/score-import-test.musicxml) 和 [识谱 PDF](test-assets/五线谱识谱测试.pdf)。

### 5. 分析课堂录音或个人练唱

打开 **音频分析**，先选分析方式，再选歌曲和录音：

- 课堂整体分析：上传课堂录音；参考旋律可选。
- 单人练唱逐音评测：选择练唱录音和参考旋律；混音参考需要 Demucs 支持人声分离。

分析以后台任务执行，页面会显示步骤与进度。完成后可打开完整结果，并将记录绑定到教案。输入的录音质量和参考素材与当前歌曲的匹配程度会直接影响结果。

### 6. 记录课堂反馈并归档

打开 **课堂反馈**，选择已保存教案，可选关联同一教案的音频分析；填写整体效果、亮点、问题和下一次改进，然后保存。右侧已带入的音频记录卡片可打开该分析详情。

在 **教学档案** 页面可以分别检索教案、音频分析记录和课堂反馈记录；教案可编辑并导出 Word 或 PDF。

## 本地运行

### 环境准备

- Windows、macOS 或 Linux；
- Python **3.11**（建议使用 64 位版本）；
- Git；
- Chrome 或 Edge 等现代浏览器；
- 首次安装依赖需要网络连接。

项目会把 Python 包装在仓库自己的 `.venv` 虚拟环境中，不应把依赖安装到 Anaconda 或系统 Python 的全局环境。

### Windows（推荐：项目启动脚本）

在 PowerShell 中运行：

```powershell
git clone https://github.com/Echo-cln/Music_Assisted_Teacher.git
cd Music_Assisted_Teacher
 .\\setup.bat
```

首次设置完成后启动：

```powershell
 .\\run.bat
```

启动脚本会打开 <http://127.0.0.1:8000>。如果浏览器没有自动打开，手动访问该地址。FastAPI 接口文档在 <http://127.0.0.1:8000/api/docs>。

后续每次使用只需在仓库目录运行：

```powershell
 .\\run.bat
```

关闭运行中的 PowerShell 窗口或按 `Ctrl+C` 可停止本地服务。

### macOS / Linux

```bash
git clone https://github.com/Echo-cln/Music_Assisted_Teacher.git
cd Music_Assisted_Teacher
bash setup.sh
bash run.sh
```

然后打开 <http://127.0.0.1:8000>。若脚本没有执行权限，可先运行 `chmod +x setup.sh run.sh`，再使用 `./setup.sh` 与 `./run.sh`。

### 首次体验账号

`setup.bat` / `setup.sh` 会准备数据库与演示数据。默认演示账号：

```text
用户名：demo
密码：demo123456
```

这是公开写在代码里的本地演示凭据，只用于个人本机体验。不要把使用该账号的实例直接开放给互联网访问。注册新账号需要配置邮件验证码服务。

### 手动启动（排查脚本问题时）

在仓库根目录：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

macOS / Linux：

```bash
.venv/bin/python -m uvicorn app.main:app --app-dir backend --reload --host 127.0.0.1 --port 8000
```

## 模型与可选功能配置

初始化时项目会从 `backend/.env.example` 复制出 `backend/.env`。打开这个本机文件，按所使用的模型服务配置。默认示例：

```dotenv
AI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
AI_API_KEY=填写深度模型服务的真实密钥
AI_MODEL=glm-5.3-flash
AI_REASONING_EFFORT=low
AI_MAX_TOKENS=32768

AI_FAST_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
AI_FAST_API_KEY=填写快速模型服务的真实密钥
AI_FAST_MODEL=doubao-seed-2-0-mini-260428
AI_FAST_REASONING_EFFORT=low
AI_FAST_MAX_TOKENS=32768

CLASSROOM_INSIGHT_ENABLED=true
CLASSROOM_INSIGHT_MAX_TOKENS=1800
```

接口地址、模型名和密钥必须匹配服务商的配置与账户权限。没有填对应密钥时，依赖该模型的生成/分析功能不会正常返回模型结果；不影响本地登录、资源浏览、键盘输入等不依赖该服务的功能。密钥只能保存在 `backend/.env` 或受信任的服务端密钥配置中，**不要写入前端文件或提交到 GitHub**。

### 邮箱注册验证码（可选）

若需要通过邮箱注册，需在 `backend/.env` 填写邮件服务提供商的 SMTP 设置：

```dotenv
SMTP_HOST=
SMTP_PORT=465
SMTP_USERNAME=
SMTP_PASSWORD=
SMTP_FROM=
```

### 混音参考的人声分离（可选）

Windows：先完成 `setup.bat`，再运行：

```powershell
.`setup_audio_pro.bat
```

macOS / Linux：

```bash
.venv/bin/python -m pip install -r backend/requirements-audio-pro.txt
```

Demucs 首次使用需要下载模型权重，速度受网络影响。课堂整体分析不要求安装 Demucs；单人练唱使用原唱/伴奏混音时才需要它。

### 五线谱图片/PDF 识别（可选）

MusicXML 和 MIDI 不需要 OCR 软件。图片/PDF 识谱需要在运行 FastAPI 的电脑上安装 Audiveris，并在 `backend/.env` 指定可执行命令：

```dotenv
AUDIVERIS_COMMAND=C:\\Program Files\\Audiveris\\bin\\Audiveris.bat
OMR_TIMEOUT_SECONDS=180
```

如果安装目录提供 `Audiveris.exe`，可填写该实际路径；也可以使用 `java -jar` 启动 Audiveris。安装版的文件名称和路径因版本而异。识谱后请人工核对音高、调号、节奏、附点和声部。

## 数据保存位置与隐私

默认本地配置使用 SQLite：

- 数据库：`backend/data/zhiban.db`
- 音频和其他上传文件：`backend/data/uploads/`
- 浏览器本机音色库：当前浏览器站点数据中的 IndexedDB
- 运行配置和 API 密钥：`backend/.env`

定期备份数据库和需要保留的上传文件。切勿提交真实用户数据库、录音或 `.env`。清除浏览器站点数据会删除本机 SF2 音色库；清除数据库或上传目录会影响教学档案与媒体文件。

本地模式下，数据保存在运行服务的这台电脑，不会自动和队友的电脑同步。把数据库地址改为 Supabase 只会连接云端数据库；音频、乐谱等媒体文件还需要配置对象存储，并保证文件本体已上传。团队协作或远程使用前，应另行确认数据库、文件存储、备份、账号安全与网络访问方案。

## 技术组成

| 层 | 技术 |
| --- | --- |
| 前端 | HTML、CSS、原生 JavaScript ES Modules |
| API | Python 3.11、FastAPI、Uvicorn、Pydantic |
| 数据访问 | SQLAlchemy；本地默认 SQLite，可配置 PostgreSQL |
| 教案生成 | OpenAI 兼容接口适配；可分别配置快速与深度模型 |
| 音频处理 | librosa、NumPy、SciPy、Basic Pitch；Demucs 为可选人声分离 |
| 乐谱 | MusicXML / MIDI 导入；图片/PDF 识谱通过可选 Audiveris |
| 音色播放 | 浏览器 Web Audio、采样播放与用户导入的 SF2 |

应用启动时由 FastAPI 初始化数据库并同时托管 `frontend/` 静态文件，因此本地开发不需要单独启动 Node.js 前端开发服务器。

```powershell

.\.venv\Scripts\python.exe -m pytest -q
```

macOS / Linux：

```bash

```

测试代码位于 `backend/tests/`。自动测试不能替代真实服务验收：模型调用需要有效 API 密钥；Demucs 需要额外安装；图片/PDF 识谱需要本机 Audiveris；真实 SF2 音色需要拥有并导入相应音源文件。

工作台的手工验收步骤和测试旋律见 [WORKBENCH_ACCEPTANCE.md](docs/WORKBENCH_ACCEPTANCE.md)，音频计算说明见 [AUDIO_ANALYSIS_METHOD.md](docs/AUDIO_ANALYSIS_METHOD.md)。

## 已知边界

- 模型生成效果、时长和费用由所选模型服务、密钥权限、网络和上下文长度共同决定；教案需教师审阅。
- 音频结果依赖录音采样率、设备、环境噪声、混响、人数及参考素材；课堂整体分析与个人逐音比较是两种不同任务。
- 未配置人声分离时，不应把原唱/伴奏混音当成干净人声参考。
- 图片/PDF 识谱依赖外部 Audiveris，输出可能漏音或误读，必须人工校正。
- 乐器选项不等于每种乐器都自带可授权的真实采样。实际音色由内置采样与用户导入音色包决定。
- 当前本地运行不是多用户在线托管：本机 SQLite、上传目录和浏览器音色库不会自动同步到队友设备。
- 仓库尚未包含 `LICENSE` 文件。公开可见不等于已授予复制、修改或再分发许可；第三方依赖、模型和音源分别遵守各自条款。
