# 教学助手模块

## 入口与对话

侧栏“教学助手”是跨模块提问和资料检索的统一入口。对话按教师隔离并保存在数据库，可新建、重命名、切换和删除。教案生成仍由“教案生成”流程负责；教学助手里的问题和资料查询不会直接写入教案。

助手可结合所选班级推荐歌曲，说明年级、地区、节奏或音域等匹配依据。教师选择“围绕歌曲备课”后才进入教案生成页面继续确认，不会因为询问推荐而立即生成。

教案详情和课堂反馈记录可带着班级、教案、反馈及音频记录上下文打开教学助手。课堂反馈编辑页也能把尚未保存的教师观察带入讨论；这些文本会被标为本次未保存输入，不会冒充历史档案。

教学档案与课堂反馈归档可按班级筛选；助手会话也保存本次班级范围，切换班级时清除旧班级关联的来源上下文，避免把旧班级观察带入新班级讨论。

## 检索范围

助手可检索教师可访问的班级画像、教案及历史版本、课堂反馈、歌曲和教学资源、已保存音频分析与音频文件元数据、编曲工程和乐器音色包。每条回答附带来源类型、名称和记录时间。检索摘要会转换成可读文字，不把数据库字典、原始 JSON 或完整音频结果直接塞进对话。

目前音频文件本体仍由音频页面播放。助手可以引用保存的分析结果和文件元数据，但不会声称听过尚未分析的录音。检索按教师权限、所选班级和明确提到的歌曲过滤；没有指定班级、歌曲或具体记录时，不会拿最近一条录音充当答案。引用反馈里的音频前，会同时核对歌曲、教案、课堂记录及录音文件的关联；不匹配的旧记录会保留并显示提醒，但不会作为本课证据。

反馈页的音频选择只列出同一首歌、同一班级且尚未绑定其他课堂的记录，或已经属于当前教案的分析。保存接口会再次校验，避免仅靠前端筛选。音频分析响应会明确返回歌曲、教案、课堂记录和班级标识，供界面安全筛选。

模型若意外返回 Python 字典或 JSON，对话会尝试提取其中的自然语言答复或将已知备课字段转成中文说明；无法安全整理时不会把原始结构当作正常回复展示。对话请求长度上限提高到 4000 字符，并在调用模型时截取上下文，避免普通历史回复触发 1200 字符校验错误。

## 操作安全

对话助手可解释资料、列出检索结果并提出教案调整方向。普通提问和查歌不会改动教案。选择“围绕歌曲备课”或“带入教案助手”后，教师仍需在教案生成流程确认生成或调整；已有教案不会由检索操作覆盖。

## 数据和限制

对话表在应用启动时由现有 SQLAlchemy `create_all` 初始化方式创建。消息记录上限为每段对话最近 200 条；回答上下文使用最近 10 轮。当前检索使用数据库关键词匹配，不是向量检索；后续可在评测召回和误召回后再接语义索引。
