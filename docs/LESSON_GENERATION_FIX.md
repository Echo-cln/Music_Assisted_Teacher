# 教案生成修复说明

本次仅修改两处后端服务：

1. `backend/app/services/lesson_service.py`
   - 恢复旧版完整课堂骨架：情境导入、匹配教学活动、分句学唱、难点练习、展示评价。
   - 五个阶段的时间仍由 `duration_minutes` 动态分配，合计等于本课时长。
   - 新增结构保护：模型即使漏掉或篡改 timeline 项，也不能删除原有阶段、阶段名或时长；模型只会增强对应环节的教师活动和学生活动。
   - 调整教案时同样保护既有流程。

2. `backend/app/services/ai_provider.py`
   - 使用 JSON 序列化请求，不再把 Python 字典字符串直接传给模型。
   - 明确模型职责：丰富可直接执教的教师话术与学生活动，不能重排、压缩或删除课堂流程。
   - 保留新版本的模型适配层、重试机制和多模型参数接口。

前端、数据库、GenerationJob 与 AI 引擎页面均不需要修改。
