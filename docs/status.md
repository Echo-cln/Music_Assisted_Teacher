# 项目完成状态

## 已完成

- FastAPI + SQLAlchemy + SQLite + 原生前端完整工程
- 教师注册、登录、退出、HttpOnly Cookie 登录态
- 多教师数据隔离：班级、教案、课堂记录、反馈、上传音频均按教师归属
- 系统公共知识库 + 教师个人知识库双层资源模型
- 教学资源库页面支持新增、编辑、删除个人资源；系统资源可复制为个人资源
- Excel 歌曲、游戏、乐理、易错点导入脚本
- 当前内置 191 首歌曲、50 条游戏、54 条乐理、25 条易错纠正资源
- 班级画像新增、查询、修改
- 智能推荐 / 手动指定双模式备课
- 规则版教案骨架即时生成
- 智谱 GLM 后台增强生成
- GenerationJob 持久化后台任务：切换页面、刷新页面不会丢失当前生成状态
- 全局 AI 生成状态卡：读取班级画像 → 知识库检索 → 规则骨架 → AI 优化 → 结构校验
- GLM 输出 token 优化：数据库依据不要求模型重复输出
- 教案调整、确认保存、课堂记录
- 音频上传、波形对比、课后反馈与画像回流
- Windows / macOS / Linux 启动脚本
- 后端单元测试通过
