# 本轮修复清单

## 已完成

- [x] GLM-5.3/GLM-5.3-Flash 使用显式 `reasoning_effort` 与更大的正文预算，避免隐藏推理耗尽输出。
- [x] 快速模式保持“只压缩篇幅”的提示词契约；不再把空响应或缺字段响应伪装成成功。
- [x] 模型包装对象兼容（`enhancement`、`lesson`、`data`、`content`、`result`），并保留实际字段诊断。
- [x] 生成任务进度从 5% 开始，按真实 SSE 正文分片递增；失败时保留最后真实进度。
- [x] 编曲工程列表改为轻量摘要，打开单个工程时才读取完整音符，减少页面卡顿。
- [x] 乐谱上传显示 0→65% 上传、70% 服务器读取、96% 解析载入、100% 成功/失败。
- [x] Audiveris 缺少 OCR 语言包时返回明确安装位置，不再只显示退出码 1。
- [x] SF2 校验 RIFF/sfbk 文件头，SoundFont2 解析器提供两个固定版本 CDN 入口和具体失败原因。
- [x] 逐音评测改为“人声质量门 → 主旋律 DTW 对齐 → 音符片段评测”；不再对混音原唱直接使用 Basic Pitch 转写伴奏。
- [x] 混音参考改为优先用 Demucs 分离人声；未安装或分离失败时返回可操作的不可评分原因，绝不输出伪 0 分。
- [x] 课堂分析的每个分段反馈附带可用人声比例、音高离散或起音节拍证据，不再只有固定阈值文案。
