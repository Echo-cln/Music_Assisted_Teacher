# 数字乐器与智能编曲工作台验收清单

本清单把“代码已写入”和“外部音源/识谱引擎已在目标机器运行”分开记录，避免把演示当成功能。

## 一、和弦与主题（无需外部安装）

在工作台输入旋律、BPM 设为 `96`，依次点击“生成 / 更新多轨编曲”。

| 测试旋律（每四个音为一小节） | 预期调性 | 预期和弦时间轴 |
| --- | --- | --- |
| `C4 E4 G4 E4 A4 C5 E5 C5 F4 A4 C5 A4 G4 B4 D5 B4 C4 E4 G4 C5` | C 大调 | `C – Am – F – G – C` |
| `G4 B4 D5 G5 C5 E5 D5 G5` | G 大调 | 时间轴显示 G 调对应和弦 |
| `A4 C5 E5 A5 D5 F5 E5 A5` | A 小调 | 时间轴显示 A 小调对应和弦 |

对第一条旋律分别选择“乡土抒情、欢快律动、童谣清新、器乐合奏”。同一旋律的和弦可以相同（和声由旋律决定），但钢琴、吉他与打击乐的**起点和时值**必须不同：欢快律动最密，童谣清新最简，器乐合奏以长音/对位为主。

## 二、真实采样播放

- 钢琴、小提琴、原声吉他：首次点“试听旋律”或“从头播放”时应显示采样加载进度，随后显示“真实采样已就绪”。再次播放会复用已加载样本。
- 古筝、二胡、非洲鼓：没有音源包时必须提示“已跳过该轨”，不能用普通合成波形冒充。
- 将**你拥有课堂使用/再分发授权**的单音色 `.sf2` 文件选择给对应乐器后，状态会显示其内部音色名；重新试听，应不再提示该轨缺音源。文件只保留在浏览器当前会话，未上传服务器。

当前实现使用 [smplr](https://github.com/danigb/smplr)（MIT）提供公开采样钢琴、GM 小提琴和原声吉他。不要把来源、许可不明的 SF2 提交进本仓库。

## 三、图片/PDF 五线谱识别

1. 从 Audiveris 官方发布页安装 Audiveris（不要使用名称相近的非官方站点）。
2. 在 `backend/.env` 填入实际启动命令。官方 Windows 安装包通常在 `bin` 下提供 `Audiveris.bat`；如果你下载的版本只有 `Audiveris.exe`，直接填写 `.exe` 路径即可；也可以填写 `java -jar "...\\Audiveris.jar"`。例如：

   ```env
   AUDIVERIS_COMMAND=C:\Program Files\Audiveris\bin\Audiveris.bat
   OMR_TIMEOUT_SECONDS=180
   ```

3. 重启 `run.bat`，在工作台导入清晰、正向、单页的 PNG/JPG/PDF 五线谱。
4. 成功条件：页面显示“已导入钢琴卷帘；请逐小节核对…”，并创建一个 `source_kind=omr` 的工程；五线谱预览、旋律文本和卷帘均有音符。
5. 失败条件必须可读：未配置时为 HTTP 503 且告诉你填写 `AUDIVERIS_COMMAND`；识别失败时返回 Audiveris 的退出码和日志摘要；超过 180 秒提示裁剪为清晰单页后重试。

Audiveris 为 AGPL-3.0 的本机外部程序；本项目只调用你本机安装的可执行文件，不打包其二进制文件。图片识谱没有保证 100% 正确，尤其应人工核对调号、附点、连音、三连音和多声部节奏。
