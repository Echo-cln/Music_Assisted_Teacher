# 音频分析实现与升级边界

## 当前版本已经真实实现

- 上传后的课堂录音和参考音频保存在服务端，并可在教学档案中回听。
- 以 `librosa.pyin` 提取主音高轨迹，输出整体及分段音高稳定度。
- 输出节拍稳定、力度层次、录音清晰度、分段关注点和教学建议。
- 有参考音频时：将两条主音高轨迹归一化到同一时间轴，先扣除整体音高偏移，再计算中位偏差（cents）、疑似跑调帧占比和四段提示。

## 结果解释

该比对只适用于单人或主声部清晰、参考音频和录音演唱同一旋律的情况。课堂合唱、强伴奏、环境噪声或两段录音速度差异很大时，结果只作教学参考，不能作为个人考级或“绝对跑调”结论。

## 后续专业增强建议

1. **Essentia + CREPE**：用于更稳健的旋律/基频提取、节拍、分段和置信度。Essentia 有 Python 与 JavaScript 接口，适合本项目继续在后端落地。
2. **Spotify Basic Pitch（本版本已接入单人练唱模式）**：用于把参考旋律转写成 note events / MIDI，再与单人录音的连续音高对齐，输出“第几个音偏高/偏低多少 cents”。运行 `pip install -r requirements.txt` 即会安装；Windows / Python 3.11 默认可使用其 ONNX 推理运行时。
3. **人声分离（可选）**：如果课堂录音带伴奏，先做人声分离再跑音高/音符级分析；否则伴奏会显著降低准确性。

当前版本已完成保存、回听、分段稳定度、参考轨迹对比和 Basic Pitch 单人逐音评测闭环。若后续需要更接近专业声乐软件的准确度，可再让教师上传标准 MIDI/曲谱，并增加人声分离；不要把任何第三方转写结果直接显示成没有置信度的“跑调判定”。
