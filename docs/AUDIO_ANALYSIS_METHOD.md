# 音频分析方法与结果边界

更新日期：2026-10-07

## 课堂整体分析

课堂整体分析面向合唱、课堂录音和带环境声的音频。后端使用 FFmpeg 解码音频，并以 librosa 的 pYIN 提取候选主音高轨迹与置信度；另结合波形能量、起音/节拍等信号形成分段线索。若配置教学模型，模型只依据已提取的时段和指标组织课堂建议，分析失败不应伪装成模型验证过的课堂结论。

页面上的音高稳定、起音间隔规律、力度变化和清晰度是声学估算值。它们受多人合唱、伴奏、混响、手机麦克风位置、噪声和录音剪辑影响，不能代表某个学生的水平，也不能直接解释为“跑调率”。

没有参考旋律时只能观察课堂录音本身，无法判断旋律是否唱准。有参考旋律也不代表适合逐音评测：参考和录音必须是同一主旋律，且人声可分辨。

## 单人练唱与参考音源

单人逐音评测使用参考主旋律和学生录音进行音高轨迹估计与动态时间规整（DTW）对齐。混音参考先尝试用 Demucs 分离人声；如果没有安装或分离失败，应显示无法评分原因，不把伴奏轨或低音轨当成人声参考，也不应生成虚假的零分结果。比对过程还使用置信度、可用音高比例和偏移约束，仍不能替代人工听辨。

适用条件：

- 尽量使用一人演唱、少混响、少噪声的录音；
- 参考素材与练唱内容使用相同旋律、调性与段落；
- 混音参考需要能成功分离出人声；
- 参考音频和练唱音频都应覆盖完整的待比对乐句。

## 教学建议如何形成

系统将录音按时间段整理已计算的声学特征，再结合教案目标生成可执行提示。建议应包含对应时间或明确依据，并转成教师可观察、学生可完成的动作。模型不得凭空补出音频中不存在的课堂事件、学生个体表现或成绩。若证据不足，应说明局限而不是套用固定的优劣评价。

## 下一步专业验证

要提升准确性，首先要建立一组经音乐教师标注的录音样本：录音设备与距离、班级人数、参考曲目、人工标注的节拍/音高现象、可接受误差都需记录。然后比较算法和人工结果，按不同录音环境分别报告误差。只有完成这项评估后，才适合决定是否更换为 CREPE、Essentia 或其他算法；增加模型名称本身不会保证准确。

建议的验收分层：

1. 用已知单音和简单旋律验证基频与音符偏差；
2. 用同一学生的清唱参考与练唱验证对齐和逐音反馈；
3. 用有伴奏原唱验证 Demucs 是否分离出正确主唱；
4. 用真实课堂录音核对声学线索和时间段；
5. 让音乐教师盲评建议的具体性、真实性和课堂可执行度。

在收集并标注真实样本之前，不应把启发式分数用于学生排名、成绩或能力标签。
